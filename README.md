# Credit Risk Prediction

This project explores credit-default prediction with a Jupyter notebook. It covers data quality checks, exploratory analysis, leakage-safe preprocessing, model comparison and tuning, threshold selection, held-out evaluation, feature importance, and a saved inference pipeline.

## Project files

- `Credit_Risk_Prediction.ipynb` — end-to-end analysis and model training.
- `credit.csv` — dataset used by the notebook.
- `Credit Risk Analysis.pptx` — project presentation.
- `outputs/` — saved model bundle and result tables generated by the notebook.

## Requirements

Python 3.10 or later is recommended. Install dependencies in a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

If PowerShell blocks virtual-environment activation, install with `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`.

## Run the notebook

Start Jupyter from the project directory:

```powershell
jupyter notebook
```

Open `Credit_Risk_Prediction.ipynb` and run its cells from top to bottom. The notebook reads `credit.csv` from the project root and writes model and analysis outputs to `outputs/`.

## Reported test-set results

The saved analysis reports 75.0% accuracy, 78.3% recall for defaults, and 0.843 ROC-AUC on the held-out test split. See `outputs/final_test_metrics.csv` for the complete metrics. These results describe this dataset and split; they are not a guarantee of performance on other populations or production data.

## Responsible use

This is an educational analysis, not a production credit-decision system. Credit decisions can materially affect people; any real-world use requires appropriate legal, fairness, privacy, security, and model-governance review.
